# v0.96 — Synthesize Alternate Takes Queue

The Synthesize tab can now queue multiple independent takes without waiting for the previous take to finish.

## Behavior

- Clicking **Generate** repeatedly queues a new job on every click.
- **Queue takes** accepts 1–20 takes from one click and defaults to 1.
- Every click snapshots the current text, engine, profile, reference audio/transcript, Qwen x-vector setting, Chatterbox sentence-splitting setting, and `engine_options` value before any request is submitted.
- Editing the form after clicking does not alter jobs already queued.
- The Generate button remains available while earlier takes are queued or running.
- The Synthesize status area reports compact aggregate counts for submitting, waiting, running, finished, and failed/canceled takes.
- Queue-count state is remembered with the rest of the Synthesize form.

## Diagnostics and performance

- UI diagnostics record queue clicks, compact snapshot metadata, accepted job IDs, request failures, job completion, and final aggregate results.
- Diagnostics record text length and a short preview rather than dumping long scripts.
- The queue adds no audio elements or hidden take panels to the Synthesize tab.
- Jobs continue to use the v0.95.5 render budget and lazy Tagged Script detail rendering.

## Implementation layout

v0.96 is materialized directly into `webui/tts_webui.py`: the existing application remains intact, the queue control is added beside Generate, and a compact override script extends the existing Synthesize and form-state functions. Installation remains `bash webui/install.sh`.
